## 5.2 模型相关配置

### 5.2.1 LLM模型配置

```python
# 主LLM模型
LLM_MODEL = "tongyiqianwen72b"              # 通义千问72B
LLM_MODEL_inference = None                  # 推理型模型（带括号关键词时使用）

# 表格摘要专用模型
TABLE_SUMMARY_MODEL = "tongyiqianwen72b"

# Prompt策略
SPLIT_LLM_INVOKE = 1                        # 是否拆分LLM调用
PROMPT_SELF_CONSISTENCY = False             # 是否使用自一致性机制
```

### 5.2.2 Embedding模型配置

```python
# 模型名称
EMBED_MODEL = "bge-m3_fine:fp16"

# 模型路径
EMBEDDING_MODEL_PATH = r"check_points/bge-m3"

# 适配器路径（可选，用于微调）
ADAPTER_PATH = None
PEFT_LORA_ADAPTER_PATH = None

# 是否使用Transformer加载
USETRANSFORMER = False
```

### 5.2.3 Rerank模型配置

```python
# Rerank模型路径
RERANK_MODEL_PATH = "check_points/ft_bge-reranker-large_20250219_003840"

# Top-K配置
EXTRACT_RERANK_TOP_K = 5                    # 提取模式
CHECK_RERANK_TOP_K = 60                     # 复核模式

# 文本最大长度
TEXT_MAX_LENGTH = 512
```

## 5.4 分块配置

```python
# 分块分隔符
CHUNK_SEPARATORS = ["\n\n\n", "\n\n", "\n", "。", "！", "？", "，", " "]
```

## 5.7 配置最佳实践

### 5.7.1 生产环境推荐配置

```python
# 模型配置
LLM_MODEL = "tongyiqianwen72b"
EMBED_MODEL = "bge-m3_fine:fp16"
EXTRACT_RERANK_TOP_K = 5
CHECK_RERANK_TOP_K = 60

# 开关配置
EXTRACT_MODEL_RERANK_SWITCH = 1  # 必开
EXTRACT_MODEL_SOURCE_SWITCH = 1  # 必开
RAGAS_SWITCH = 0                 # 关闭（节省时间）

# 检索配置
SEARCH_KWARGS = {"k": 120}
CHUNK_SIZE = 512
CHUNK_OVERLAP_ratio = 0.2
```
