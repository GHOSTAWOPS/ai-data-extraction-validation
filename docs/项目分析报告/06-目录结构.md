# 第六章：目录结构详解

## 6.1 完整目录树

```
AI数据提取与辅助校验系统/
├── main.py                                 # 主程序（Gradio UI + 业务逻辑），1996行
├── config.py                               # 全局配置类
├── requirements.txt                        # Python依赖清单
│
├── models/                                 # AI模型层
│   ├── extract_model.py                   # 数据提取核心（call_extract_model）
│   ├── check_model.py                     # 数据校验核心（旧版）
│   ├── new_check_model.py                 # 数据校验核心（新版，推荐使用）
│   ├── llm_model.py                       # LLM模型加载器
│   ├── embedding_model.py                 # Embedding模型加载器
│   ├── new_rerank_model.py                # Rerank模型（微调版）
│   ├── prompt_engineering.py              # Prompt模板库
│   ├── vectorstore.py                     # ChromaDB操作封装
│   ├── hybrid_search.py                   # 混合检索实现
│   └── rerank_only.py                     # 仅Rerank功能
│
├── data_processor.py                       # 文档解析工具（旧版）
├── data_processor_new_zbb_structured.py   # 新版结构化解析器
│
├── utils/                                  # 工具函数集
│   ├── utils.py                           # 通用工具（分块、装饰器等）
│   ├── xlsx_utils.py                      # Excel文件操作
│   ├── docx_utils.py                      # DOCX文件操作（DocxManager）
│   ├── logger_util.py                     # Loguru日志配置
│   ├── file_cleanup.py                    # 自动清理临时文件
│   └── MergeDoc.py                        # 多文档合并工具
│
├── QueryRewrite/                           # 查询重写模块（可选增强）
│   ├── core.py                            # 核心重写逻辑
│   ├── context.py                         # 上下文管理
│   ├── utils.py                           # 辅助工具
│   └── __init__.py
│
├── RAGAS/                                  # 答案评估模块
│   └── ragas_eval_correct.py              # RAGAS评估器实现
│
├── Structured/                             # 结构化数据处理
│   └── DataStructure.py                   # 数据结构定义
│
├── check_points/                           # AI模型文件目录
│   └── bge-m3/                            # BGE-M3 Embedding模型
│       ├── pytorch_model.bin              # 主模型权重
│       ├── colbert_linear.pt              # ColBERT线性层
│       ├── sparse_linear.pt               # 稀疏检索线性层
│       ├── config.json                    # 模型配置
│       ├── tokenizer.json                 # 分词器
│       └── onnx/                          # ONNX加速版本
│           └── model.onnx
│
├── extract_templates/                      # 提取模板存储
│   ├── 客户级/                            # 客户级模板
│   └── 系统级/                            # 系统级模板
│
├── output_excels/                          # 输出文件目录
│   ├── extract/                           # 提取结果
│   ├── check/                             # 复核结果
│   └── chunk_txt/                         # 分块调试信息
│
├── output_jsons/                           # JSON缓存目录
│   ├── table_jsons/                       # 表格信息缓存
│   ├── rerank_jsons/                      # Rerank结果缓存
│   └── extract_asr_jsons/                 # 评估中间结果
│
├── css/                                    # 前端样式
│   └── style2.css                         # Gradio自定义CSS
│
├── project_instructions/                   # 使用说明文档
│   └── markdown/
│       ├── extract.md                     # 提取功能说明
│       ├── verify.md                      # 复核功能说明
│       ├── preprocess.md                  # 预处理功能说明
│       └── media/                         # 文档图片资源
│
├── downloads/                              # 下载文件临时目录
│   └── 辅助工具.zip                       # 辅助工具包
│
├── data/                                   # 临时数据目录
│   ├── tmp_merged/                        # 合并文档临时目录
│   └── tmp_cleaned/                       # 清理文档临时目录
│
├── assets/                                 # 静态资源
│   └── images/                            # 图片资源
│
└── logs/                                   # 日志文件目录
    └── app.log                            # 应用日志

```

## 6.2 核心目录说明

### 6.2.1 models/ - AI模型层

**作用**：封装所有AI模型的加载、推理和交互逻辑

**关键文件**：

| 文件 | 行数 | 核心功能 |
|------|------|---------|
| extract_model.py | 39338 | 数据提取核心流程 |
| new_check_model.py | 44866 | 数据复核核心流程 |
| prompt_engineering.py | 60457 | Prompt模板库 |
| new_rerank_model.py | 17124 | Rerank精排实现 |
| llm_model.py | 3174 | LLM模型选择与加载 |
| embedding_model.py | 4992 | Embedding模型加载 |

### 6.2.2 utils/ - 工具函数集

**作用**：提供各类辅助功能

**关键文件**：

- **utils.py**：通用工具（分块、时间装饰器、错误处理）
- **xlsx_utils.py**：Excel读写、模板解析、答案填充
- **docx_utils.py**：DOCX高亮标注、超链接插入
- **logger_util.py**：日志配置（Loguru）
- **file_cleanup.py**：自动清理临时文件
- **MergeDoc.py**：多DOCX合并

### 6.2.3 check_points/ - 模型文件

**BGE-M3模型文件**：

| 文件 | 大小 | 说明 |
|------|------|------|
| pytorch_model.bin | ~2.3GB | 主模型权重 |
| colbert_linear.pt | ~300MB | ColBERT线性层 |
| sparse_linear.pt | ~300MB | 稀疏检索线性层 |
| onnx/model.onnx | ~1.2GB | ONNX推理加速版 |

### 6.2.4 output_*/ - 输出目录

**输出文件组织**：

```
output_excels/extract/
└── output_20250110_143022.xlsx        # 提取结果

output_excels/check/
└── output_20250110_154530.zip         # 复核结果（包含多个文件）
    ├── excel_output.xlsx
    ├── 装机容量_高亮.docx
    └── ...

output_jsons/table_jsons/
└── 芦山水电站_table_info.json        # 文档解析缓存
```

### 6.2.5 extract_templates/ - 模板管理

```
extract_templates/
├── 客户级/
│   ├── 芦山项目_模板.xlsx
│   └── ...
└── 系统级/
    ├── 水电站通用模板.xlsx
    └── ...
```

## 6.3 文件大小统计

| 目录/文件 | 大小 | 说明 |
|----------|------|------|
| check_points/ | ~4GB | AI模型文件 |
| output_jsons/ | ~50MB | JSON缓存（随使用增长） |
| output_excels/ | ~10MB | 输出文件（定期清理） |
| logs/ | ~5MB | 日志文件（定期清理） |
| 总大小 | ~4.5GB | 不含用户数据 |
