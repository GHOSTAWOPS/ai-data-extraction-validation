**Rerank实现**（models/new_rerank_model.py）：
```python
def rerank_docs(query, documents, top_k):
    # 加载Rerank模型
    model = FlagReranker(CONFIG.RERANK_MODEL_PATH, use_fp16=True)

    # 构造Query-Doc对
    pairs = [[query, doc.page_content] for doc in documents]

    # 计算相关性分数
    scores = model.compute_score(pairs)

    # 排序并返回top-K
    ranked_indices = np.argsort(scores)[::-1][:top_k]
    return [documents[i] for i in ranked_indices], scores[ranked_indices]
```

def read_xlsx_sheet(wb, verify=True):
    if verify:
        # 检查工作表名称：output_excels → 第1次，output_excels_1 → 第2次
        time_check = 0
        for sheet in wb.sheetnames:
            if "_" in sheet:
                parts = sheet.split("_")
                if parts[-1].isdigit():
                    time_check = max(time_check, int(parts[-1]))
        return wb.active, time_check

**DocxManager核心功能**（utils/docx_utils.py）：

```python
class DocxManager:
    def __init__(self, file_path, save_path):
        self.original_doc = pyDocument(file_path)
        self.save_path = save_path
        self.saved_docs = {}  # {keyword: saved_path}

    def highlight_and_save(self, keyword, proof_list):
        """
        高亮标注并保存
        proof_list: [
            {"page": 12, "text": "装机容量为120MW", "score": 0.95},
            ...
        ]
        """
        # 复制原文档
        new_doc = copy.deepcopy(self.original_doc)

        # 遍历proof，在文档中查找并高亮
        for proof in proof_list:
            text_to_find = proof["text"]
            for paragraph in new_doc.paragraphs:
                if text_to_find in paragraph.text:
                    # 高亮显示
                    for run in paragraph.runs:
                        if text_to_find in run.text:
                            run.font.highlight_color = WD_COLOR_INDEX.YELLOW

        # 保存
        save_path = f"{self.save_path}/{keyword}_高亮.docx"
        new_doc.save(save_path)
        self.saved_docs[keyword] = save_path
        return save_path
```

    # 2. 确定存储目录

    # 4. 格式校验
    try:
        wb = read_xlsx_file(excel_file)

        _ = init_query_info_from_xlsx(ws)  # 必须包含【索引、关键词】列

def refresh_table(level: str, keyword: str):

## 3.5 模块间协作

### 3.5.1 典型工作流

```
用户操作流程：

1. 【模板管理】上传或选择模板
   ↓
2. 【文档预处理】上传DOCX，生成JSON缓存
   ↓
3. 【数据提取】选择DOCX+模板，执行提取
   ↓
   下载Excel结果
   ↓
4. 【数据复核】上传DOCX+提取结果Excel，执行复核
   ↓
   下载ZIP包（Excel+高亮DOCX）
   ↓
5. （可选）人工修正后，再次执行【数据复核】
```

### 3.5.2 数据流转

```
模板Excel → 关键词列表
              ↓
DOCX → JSON缓存 → chunks → 向量数据库
              ↓              ↓
          关键词查询 → 检索 → Rerank → LLM → 答案
                                              ↓
                                         填充到Excel
```
