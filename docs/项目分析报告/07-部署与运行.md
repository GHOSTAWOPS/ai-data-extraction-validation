# 第七章：部署与运行

## 7.1 环境要求

### 7.1.1 硬件要求

**最低配置**：
- CPU：8核+
- 内存：16GB+
- GPU：NVIDIA GPU（6GB+ VRAM），可选但强烈推荐
- 硬盘：50GB+可用空间

**推荐配置**：
- CPU：16核+
- 内存：32GB+
- GPU：NVIDIA GPU（16GB+ VRAM）
- 硬盘：100GB+ SSD

### 7.1.2 软件要求

- **操作系统**：Linux（Ubuntu 20.04+）/ Windows 10+ / macOS
- **Python**：3.8-3.11（推荐3.10）
- **CUDA**：11.7+（如使用GPU）
- **Docker**：可选，用于容器化部署

---

### 7.2.4 本地凭据与资源

将项目根目录的 `.env.example` 复制为 `.env`，填写使用的服务凭据：

- `QWEN_API_KEY`：通义千问 72B 内网服务，以及使用该服务的 RAGAS 评估。
- `DASHSCOPE_API_KEY`：阿里云 DashScope 服务。

程序从项目根目录加载 `.env`，已有系统环境变量优先。实际使用的服务必须配置对应变量；`.env` 不提交到 Git。

GitHub 仓库保存代码、文档和界面资源。模型目录 `check_points/`、本地 JSONL 数据集、RAGAS 样本、`downloads/` 中的工具压缩包以及运行输出不上传，需按功能在本地准备。提示优化使用的样本路径为 `utils/data4_20_3_only2_with_shangxiawen.jsonl`，辅助工具包路径见 `CONFIG.download_path`。

## 7.3 模型准备

### 7.3.1 下载BGE-M3模型

**方式1：自动下载**（首次运行时自动）
```python
# 代码会自动从HuggingFace下载
from sentence_transformers import SentenceTransformer
model = SentenceTransformer("BAAI/bge-m3")
```

**方式2：手动下载**
```bash
# 使用HuggingFace CLI
pip install huggingface_hub
huggingface-cli download BAAI/bge-m3 --local-dir check_points/bge-m3
```

### 7.3.2 配置通义千问API

**在 `.env` 中配置 `QWEN_API_KEY`，并在 `models/llm_model.py` 中设置服务地址**：
```python
import os

# models/llm_model.py:24-29
model = ChatOpenAI(
    base_url='http://192.168.30.25:20010/v1',  # 修改为你的API地址
    api_key=os.environ["QWEN_API_KEY"],                     # 修改为你的API Key
    model=CONFIG.LLM_MODEL,
    temperature=0,
)
```

**或使用Ollama本地模型**：
```bash
# 安装Ollama
curl -fsSL https://ollama.com/install.sh | sh

# 下载模型
ollama pull qwen2.5:7b

# 修改config.py
LLM_MODEL = "qwen2.5:7b"
```

### 7.3.3 配置Rerank模型

**如有微调模型**，放置到：
```bash
check_points/ft_bge-reranker-large_20250219_003840/
```

**否则使用默认模型**：
```bash
# 下载原始reranker模型
huggingface-cli download BAAI/bge-reranker-large --local-dir check_points/bge-reranker-large

# 修改config.py
RERANK_MODEL_PATH = "check_points/bge-reranker-large"
```

## 7.7 Docker部署（可选）

### 7.7.1 构建镜像

**创建Dockerfile**：
```dockerfile
FROM python:3.10-slim

WORKDIR /app

# 安装系统依赖
RUN apt-get update && apt-get install -y \
    git \
    build-essential \
    && rm -rf /var/lib/apt/lists/*

# 复制项目文件
COPY requirements.txt .
RUN pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

COPY . .

# 暴露端口
EXPOSE 7860

# 启动命令
CMD ["python", "main.py"]
```

**构建**：
```bash
docker build -t ai-extract:latest .
```

### 7.7.2 运行容器

```bash
docker run -d \
  --name ai-extract \
  -p 7860:7860 \
  -v $(pwd)/check_points:/app/check_points \
  -v $(pwd)/output_excels:/app/output_excels \
  --gpus all \
  ai-extract:latest
```

## 7.8 常见问题

### 7.8.1 GPU内存不足

**错误**：
```
RuntimeError: CUDA out of memory
```

**解决方案**：
1. 减小batch_size（models/new_rerank_model.py）
2. 使用半精度（use_fp16=True）
3. 使用CPU模式（移除--gpus all）

### 7.8.2 模型下载失败

**错误**：
```
ConnectionError: Can't reach HuggingFace
```

**解决方案**：
```bash
# 使用镜像站
export HF_ENDPOINT=https://hf-mirror.com
```

### 7.8.3 端口被占用

**错误**：
```
OSError: Address already in use
```

**解决方案**：
```bash
# 查找占用进程
lsof -i:7860

# 杀死进程
kill -9 <PID>

# 或修改端口
```
